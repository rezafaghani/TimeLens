# TimeLens Client

React 19 + Vite frontend for exploring provider-backed market instruments, OHLCV series, validation, and ingestion status.

## Development server

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Tests

```bash
npm test
```

Set `VITE_API_BASE_URL` if the API is not available at `/api`.
